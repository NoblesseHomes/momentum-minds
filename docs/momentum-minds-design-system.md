# Momentum Minds — дизайн-система v1.0

Документ для AI-агента, который будет верстать/собирать сайт. Направление: **"Tranzit"** — нейтральная, спокойная, слегка "транзитно-мобильная" эстетика (переклик с темами трансфера, сопровождения, релокации), без клише AI-дизайна (без кремового+терракоты, без чёрного+неона, без broadsheet-газетной сетки).

Компания: Momentum Minds s.r.o. (Чехия). B2B-компания на стыке двух направлений: Recruitment Marketing & Advertising (+ Business Support как сопутствующая организационная/логистическая/административная поддержка) и Metalworking & Assembly (см. `momentum-minds-site-concept.md` v3 — актуальное описание бизнеса; формулировка выше исторически относилась к более раннему варианту позиционирования и отменена).

- Один primary-CTA на экран/секцию максимум.

## 3. Сетка и отступы

- Контейнер: max-width `1200px`, паддинги по бокам `24px` (mobile) / `64px` (desktop)
- Колоночная сетка: 12 колонок, gap `24px` (desktop), `16px` (mobile)
- Брейкпоинты: `mobile ≤ 767px`, `tablet 768–1023px`, `desktop ≥ 1024px`
- Шкала отступов (используется для margin/padding везде): `4, 8, 12, 16, 24, 32, 48, 64, 96` px
- Вертикальный ритм между секциями: `96px` (desktop) / `56px` (mobile)

## 4. Компоненты

### Кнопки
- **Primary**: фон `--color-accent-primary`, текст белый `#FFFFFF`, radius `8px`, padding `12px 24px`, hover → `--color-accent-primary-hover`
- **Secondary**: прозрачный фон, обводка `1px solid --color-border-strong`, текст `--color-text-primary`, hover → фон `--color-surface`
- Текст кнопок — Inter 500, без подчёркивания, sentence case (не CAPS)

### Теги/бирки (сервисные метки — как в hero: MKT, BOZP, TLM, DOP, UBY)
- Форма "посадочного талона": `border-radius: 20px`
- Неактивный: фон `--color-surface`, обводка `1px solid --color-border`, текст `--color-accent-primary`
- Активный/акцентный: фон `--color-accent-primary`, текст `#FFFFFF`
- Шрифт: JetBrens Mono 500, 11–12px, uppercase

### Карточки (услуги, партнёрские предложения)
- Фон `--color-surface`, radius `16px`, padding `24px`, обводка `1px solid --color-border`
- Тень: не использовать drop-shadow — только обводка (плоский стиль направления Tranzit); при hover — обводка меняется на `--color-border-strong`, без сдвига/анимации масштаба
- Внутри: иконка (outline-стиль, 24px, цвет `--color-accent-primary`) → H3 → body-описание → (опционально) mono-тег категории

### Поля форм
- Высота `44px`, radius `8px`, обводка `1px solid --color-border`, фон `--color-surface`
- Focus: обводка `--color-accent-primary` + `box-shadow: 0 0 0 3px rgba(43,110,94,0.15)`
- Лейблы — Inter 500 14px, `--color-text-secondary`
- Ошибка — обводка `--color-danger`, текст ошибки Inter 13px `--color-danger` под полем

### Разделители
- `1px solid --color-border`, без градиентов и декоративных линий

## 5. Иконография

- Стиль: outline (контурные), единая толщина линии, без заливки
- Рекомендуемый набор: Tabler Icons (открытая лицензия, широкий охват)
- Размер: 20–24px инлайн, 32px — в карточках услуг
- Цвет по умолчанию: `--color-accent-primary`; в футере/на светлом фоне допустим `--color-text-secondary`

---

## 6. Motion (минимально, по делу)

- Переходы: `150ms ease-out` для hover/focus состояний (цвет, обводка)
- Никаких decorative-анимаций, параллакса, автоплей-каруселей
- Появление секций при скролле — опционально, простой fade+translateY(8px), `400ms`, `prefers-reduced-motion: reduce` → отключить полностью

## 7. Структура страницы и спецификация секций

### 7.1 Шапка (Header)
- Sticky, фон `--color-bg` с `1px solid --color-border` снизу при скролле
- Слева: логотип/название "Momentum Minds"
- Справа: навигация по секциям (Что предлагаем / Партнёры / Контакты) + Primary-кнопка "Связаться" (скролл к форме)
- Mobile: гамбургер-меню, тот же порядок пунктов

### 7.2 Hero — ЗАФИКСИРОВАНО, не менять без согласования
- Фон: `--color-bg` (нейтральный, без фото/видео — решение по направлению B; если позже добавится фото/видео — см. правила ниже)
- H1: `Momentum Minds — komplexní služby pro firmy i jednotlivce`
- Body large (подзаголовок): `Propojujeme různé obory, abychom vám nabídli jednoduchá a spolehlivá řešení.`
- Под подзаголовком: ряд mono-тегов услуг (MKT / BOZP / TLM / DOP / UBY), закруглённые "бирки", один тег выделен акцентным фоном (ротация или статично — на усмотрение)
- Фон hero — ЗАФИКСИРОВАНО: фоновое видео-петля "суета мегаполиса"

**Спецификация hero-видео:**
- Сюжет: людный перекрёсток/переход в европейском мегаполисе (желательно Прага, при отсутствии подходящего кадра — любой нейтральный европейский даунтаун), много пешеходов и машин в движении, ракурс сверху/с возвышения (не с уровня глаз)
- Идея: визуальная метафора "повседневной рутины/суеты", которую берёт на себя компания — прямая связка с текстом hero
- Длительность петли: 10–15 сек, без резких склеек, бесшовный зацикленный луп
- Цветокоррекция (обязательна): десатурация 60–80%, тени → `#1A1D22`, света → `#EEF0F2`, лёгкий сдвиг в `#2B6E5E`
- Оверлей: тёмный, 30–40% непрозрачности, поверх всего видео (текст hero должен читаться при контрасте AA)
- Технические требования:
  - Форматы: `.mp4` (H.264) основной + `.webm` фолбэк
  - Атрибуты: `autoplay muted loop playsinline`
  - `poster` — статичный тонированный кадр (тот же цветокоррект), показывается до загрузки видео
  - Вес файла — оптимизировать под web (target ≤ 3–5MB для 15 сек луп в разрешении 1920×1080)
- Доступность/фолбэк:
  - При `prefers-reduced-motion: reduce` — видео не запускать, показывать статичный `poster`-кадр вместо него
  - На мобильных с медленным соединением (`navigator.connection` / `save-data`) — тоже показывать статичный кадр
  - Видео декоративное — `aria-hidden="true"`, весь смысловой контент дублируется текстом, не видео

### 7.3 «Что предлагаем» (собственные услуги)
- H2 секции + короткий intro-текст (1 предложение, без конкретики — детали в карточках)
- Сетка карточек: 5 карточек (по числу услуг) — Маркетинг и реклама, Обучение BOZP, Переводы и сопровождение, Трансфер, Услуги заселения
- Desktop: 3 колонки (сетка 3+2 или auto-fit minmax(280px,1fr)), mobile: 1 колонка
- Каждая карточка: иконка → заголовок → 1–2 предложения описания → mono-тег категории (тот же код, что в hero: MKT/BOZP/TLM/DOP/UBY) для визуальной связки с hero

### 7.4 «Предложения от сторонних партнёров»
- Визуально отличать от собственных услуг компании, но в той же системе — не создавать отдельный стиль с нуля
- Отличия: у карточки партнёра — бейдж `Partner` (mono, фон `--color-accent-secondary` (охра), текст тёмный `#3D2F0A` для контраста), + иконка внешней ссылки `ti-external-link` у CTA
- Обязательно короткая поясняющая строка над блоком: что это предложения не от самой Momentum Minds, а от партнёров (важно для доверия/прозрачности)
- Карточки могут вести на внешние сайты — открывать в новой вкладке

### 7.5 Блок контактов и форма обратной связи
- Двухколоночная раскладка (desktop): слева — контактные данные (адрес, email, телефон, реквизиты фирмы/IČO), справа — форма
- Форма: поля Имя, Email, Телефон (опционально), Тема/интересующая услуга (select с теми же 5 категориями), Сообщение, чекбокс согласия на обработку данных (GDPR — обязательно для Чехии), Primary-кнопка "Odeslat" / "Отправить"
- Успешная отправка — inline-подтверждение под формой (не alert/modal), тон нейтральный: "Zpráva odeslána. Ozveme se vám co nejdříve."
- Mobile: одна колонка, контакты сверху

### 7.6 Footer
- Фон чуть темнее базового — можно `--color-surface` с верхней обводкой `--color-border`, либо инверсия в `--color-text-primary` с текстом `--color-bg` (на усмотрение агента, но не третий новый цвет)
- Содержимое: логотип, краткая навигация-дубликат, юридические реквизиты (IČO, adresa sídla), ссылки на соцсети (если есть), копирайт-строка
- Юридические/номерные данные — шрифт JetBrains Mono (перекликается со стилем "документа/реестра")

## 8. Доступность (обязательные требования)

- Контраст текста: основной текст на фоне — минимум AA (4.5:1); проверено — `#1A1D22` на `#EEF0F2` и `#FFFFFF` соответствует
- Все интерактивные элементы — видимый focus-ring (см. поля форм выше), не убирать outline без замены
- Кнопки/ссылки — доступны с клавиатуры, порядок табуляции логичный (header → hero CTA → секции → форма → footer)
- Alt-тексты для всех декоративных/контентных изображений
- `prefers-reduced-motion` — уважать (см. раздел Motion)
- Форма: явные `<label>` для всех полей, ошибки объявляются программно (aria-live или aria-describedby)

## 9. Тон копирайта (кратко)

- Единственное число уважительное "vy" (чешский), нейтрально-деловой тон, без избыточного маркетингового пафоса
- Sentence case везде (не Title Case, не CAPS), кроме mono-тегов услуг, которые всегда uppercase по дизайну
- Кнопки — глагол в начале, коротко: "Odeslat", "Kontaktovat", "Zjistit více"
